# Color Studio

**Color Studio** est un projet Python développé par Rémi Cozot (2019) pour gérer et visualiser des scènes lumineuses avec une interface graphique moderne.

Le projet inclut :  
- Chargement et visualisation de fichiers XML de configuration lumineuse  
- Interface graphique avec **PyQt5**  
- Nuages de points 3D interactifs avec **ModernGL**

---

## Installation

### Prérequis
- Python 3.8 (64 bits recommandé)  
- pip à jour

```bash
py -3.8 -m pip install -r requirements.txt
